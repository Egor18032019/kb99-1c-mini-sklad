# Учебная конфигурация «Мини-Склад»

## Описание
Учебный проект по изучению платформы 1С:Предприятие 8.3. 
Реализует минимальный контур складского учёта.

## Функциональность
- **Справочники:** Товары, Контрагенты.
- **Документы:** Поступление, Реализация (с движениями по регистру остатков).
- **Регистры:** ОстаткиТоваров.
- **Отчеты:** Остатки товаров (на СКД).

## Технологии
- Платформа: 1С:Предприятие 8.3 (учебная версия)
- Контроль версий: Git (текстовая выгрузка XML)

## Как развернуть
1. Создать новую пустую информационную базу в 1С.
2. Открыть Конфигуратор.
3. Выбрать **Конфигурация → Загрузить конфигурацию из файлов…**
4. Указать путь к корню репозитория, где лежат XML.
5. Нажать **F7** (Обновить конфигурацию базы данных).
